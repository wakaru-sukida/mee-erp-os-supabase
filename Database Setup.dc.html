ตั้งค่าฐานข้อมูล — Supabase (PostgreSQL)

เปลี่ยนแหล่งข้อมูลของทุกโมดูลจาก Google Sheet เป็น SQL จริง โดยไม่ต้องแก้ไฟล์โมดูล — ชั้น erp-kit.js › sheetsBind() จะสลับไปเรียก Supabase ให้เองเมื่อบันทึกการเชื่อมต่อสำเร็จ

สร้างตารางใน Supabase
กด สร้างสคริปต์จากชีตจริง — ระบบจะอ่านหัวตารางของทุกแท็บใน Google Sheet ปัจจุบัน ({{ tableCount }} แท็บ) แล้วประกอบ SQL ให้ชื่อคอลัมน์ตรงกับข้อมูลจริง จากนั้นวางใน Supabase › SQL Editor › New query แล้ว Run ครั้งเดียว
คอลัมน์ระบบขึ้นต้นด้วย _ (_pk · _tenant · _seq · _extra) จึงไม่ทับฟิลด์ข้อมูลจริงอย่าง id หรือ tenant_id ที่มีอยู่ในชีต · ชุดสำรอง (supabase-schema.sql) อิงข้อมูลตัวอย่างในโค้ด ใช้เฉพาะตอนเข้าถึงชีตไม่ได้
คลิกในกล่องจะเลือกทั้งหมดให้ แล้วกด Ctrl+C (Mac: ⌘C)
